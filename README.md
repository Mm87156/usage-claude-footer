# usage-footer

Mod do Claude Code: wyśrodkowany pasek nad promptem z kontekstem, limitem 5h, limitem tygodniowym i cache, plus przycisk `compact` (albo komenda `/cp`).

## Instalacja

W sesji terminalowej Claude Code:

```
/plugin install usage-footer --marketplace Mm87156/usage-claude-footer
```

Z powłoki:

```
claude plugin install usage-footer --marketplace Mm87156/usage-claude-footer
```
